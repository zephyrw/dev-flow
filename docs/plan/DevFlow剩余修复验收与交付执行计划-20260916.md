## H06：重写真实性能基准并核验轻量运行

**不得运行当前脚本后把其硬编码 PASS 当作证据。** 先修改 scripts/bench/devflow-v2.mjs，删除模拟查询和固定性能值；旧 bench-report.json 标为 invalid_simulation。

### 固定测量方法

1. 启动隔离的真实生产构建服务和 Host，记录 PID、创建时间、机器/OS/CPU/RAM、Node/Go/工具版本和样本大小。
2. 通过真实 HTTP 请求测 API，记录每次开始、结束、状态码和响应字节；p95 按排序后的第 ceil(0.95*n) 个样本计算。
3. CPU 采用被测 PID 及其平台 Host 的进程 CPU 时间增量 / 墙钟时间 ×100%，按一个逻辑核心口径；不是整机 CPU，也不是测量脚本自己的 CPU。
4. Windows RSS/WorkingSet 与累计 CPU 从真实进程计数读取；macOS 从实际进程指标读取。1 秒采样一次，结束后停止采样器，不新增常驻监控。
5. 内存统计服务+平台 Host；用户 CLI/业务 DB/浏览器单列，不能混入或隐藏。网页 heap 单独采集。
6. 数据库写入、进程启动、Git 调用、源码扫描/指纹次数采用实际事件/调用边界计数。只在显式基准模式开启，普通运行关闭。
7. 30 分钟以 100KiB/s 向真实日志入口发送确定字节流，观察背压、flush、磁盘分片、WebSocket 显示和最终内容完整性。
8. 合成 10 万路径及总量 1GiB 文本输入；通过真实 @ 查询、分页及指纹入口测量，记录首次与缓存命中。不能用 sleep 或内存数组遍历替代工作区扫描。
9. 测试进程创建账本证明平台没有在模型已完成测试后补跑测试，也没有逐原生工具调用新增权限代理进程。
10. 任何指标缺数据为 not_run/blocked；阈值按实际数值计算，不硬编码 verdict。

### 必须达到的原方案阈值

| 指标 | 通过标准 |
| --- | --- |
| 无任务且关页 | 0 模型/浏览器/测试子进程；0 源码扫描/指纹；0 idle DB 周期写入 |
| 空闲 CPU | 预热后 5 分钟平均 ≤一个逻辑核心 1% |
| 空闲平台内存 | 服务+Host ≤200MiB |
| 活动 CPU | 100KiB/s 日志流平均 ≤一个逻辑核心 5%，终局哈希单列 |
| 活动平台内存 | 30 分钟 ≤300MiB，无随日志累计的持续增长 |
| 页面增量 heap | ≤100MiB，不随长日志线性增长 |
| metadata API | 真实样本 p95 ≤200ms，读取不触发 Git/指纹/测试 |
