# DevFlow v0.4.0

本版新增执行阶段自动续接，减少模型完成部分工作后等待手动推动的情况，并完善 AGY 结果校验、工作台任务管理和工具额度展示。

## 本版更新

- **执行阶段自动续接**：模型返回 `incomplete` 后，沿用原会话、原模型及冻结配置继续剩余任务；结束原因不明确时先核对，连续三轮没有新增完成项时停止自动续接并等待用户。保留暂停、用户提问、权限审批及后续人工验收。
- **AGY 结果处理**：要求有效的成功结束事件，拒绝将失败、取消或截断流中的完成声明用于结束任务或续接；续接前核对任务与运行归属，保留明确的用户请求和失败诊断，等待当前子进程退出后再处理结果。
- **任务与项目管理**：完善任务概览布局，支持修改任务和项目名称、查看完整名称与项目路径；运行中的任务不能归档，含运行任务的项目不能移除。移除项目关联时保留项目文件及任务记录。
- **额度与弹窗交互**：Codex、AGY 额度按工具账号独立读取，不依赖当前运行角色；修正额度弹窗与模型设置面板的互斥和关闭交互。
