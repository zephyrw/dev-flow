# DevFlow 产品宣传片

## 背景与目标

本片用于介绍 DevFlow，并为后续产品文章提供截图。DevFlow 是本地运行的轻量化模型调度工作流：模型负责规划、开发、自测和代码复核，用户批准计划并验收功能，DevFlow 衔接阶段、展示进度并保留任务上下文。

当前产品已有独立模型配置、工作台和 Agy 多账号管理。宣传重点是让观众理解这些能力如何配合，不使用性能、成本或成功率承诺。用户已选择自主自由创作，制作与技术检查连续推进。

第三版以工作流职责为叙事主线，业务需求只作为界面背景；流程总览与 README 的三段式接力时间线一致。八步为：调研计划、人工审批、开发实施、自动测试、验收前质量审查、人工验收、验收后代码复核、本地提交。逐步文案和示例执行者见 `修订说明.md`，本轮视觉调整见 `修订说明-v3.md`。规划、复核和本地提交示例采用 Codex · GPT-6 Astra；实施和测试采用 Agy · Gemini 3.8 Flash。复核默认跟随规划，也可单独指定；人工步骤由用户完成。

任务内容、账号邮箱、额度、复核结论和检查结果均为虚构演示数据；截图来自真实 DevFlow 前端，不伪称已实际运行这项开发任务。浏览器拦截全部业务 API 与 WebSocket，截图过程中不修改真实账号、配置、数据库或运行任务。

## 视觉与声音

选择“清晰接力”：沿用产品的白色工作区、深色侧栏和蓝色强调，体现轻量、专业、可控。另考虑的暗色科技风会削弱真实界面的识别；纸墨风会引入无关品牌材质，因此不采用。

- 1920×1080，30fps，共 3008 帧（100.27 秒），中文标题与说明，保留模型英文名称；无旁白。
- 字体沿用 Segoe UI / Microsoft YaHei。背景 #f8fafc，表面 #ffffff，正文 #0f172a，强调 #2563eb，成功 #10b981，边界 #e2e8f0；圆角 8–16px。
- 大标题 74–170px；叙事说明 60px；辅助信息主要为 34–42px。按渲染后的实际字高检查，叙事文字至少 56px，辅助文字至少 32px。界面小字作为整体纹理，关键内容另给高清特写和大字说明。账号特写以 4 倍像素密度采集。
- 动效约 21–30 帧收敛，默认无抖动；切换模型时证据画面同步步进，额度展示保持正视。品牌落定至少停留 30 帧。
- 配乐采用克制电子节奏，另交付无配乐但保留音效版本。音乐与音效独立轨道，全部来源记录在下方“声音与授权记录”。

## 完成标准

交付两版 MP4、全部片中截图、文章用成片关键帧和可编辑工程。检查全部场景及转场、文字锐度、素材安全、音画同步、视频参数与两版画面一致性；由未参与制作的审查子代理独立复核。渲染缓存、调试图和一次性数据在检查结束后清理，保留用户所需文件和可重现制作的必要工程。

功能说明依据本次检查的本地源码与界面，不代表所有平台或所有账号均已实测通过。自动切换需要开启功能且存在符合模型、账号和额度要求的候选；无候选时保留任务进度并等待。
