# DevFlow 宣传片第二版

本片用于介绍 DevFlow 的轻量化模型调度工作流，并为产品文章保留截图。首版把业务案例和三个模型角色作为叙事主线，未充分解释完整流程，也容易让人误以为工具与模型固定。第二版以八步职责为主线，让观众知道每一步由谁完成、产出什么，以及如何自行搭配模型。

保持现有产品字体、白蓝配色和动效方向。本轮属于内容与结构修订，沿用已验证的视觉基准；先检查新镜头关键帧，再渲染全片。用户此前授权自主自由创作，连续制作与复核，无需逐镜头确认。

## 叙事安排

开场点明轻量调度；真实配置界面说明工具与模型可自定义；完整列出八步；以同步切换的页面和大字解释每步职责；保留 Agy 账号管理、双额度与自动切换；最后收束品牌。

| 步骤 | 本片示例执行者 | 说明 |
|---|---|---|
| 调研计划 | Codex · GPT-6 Astra，规划模型 | 理解需求、调研代码，形成范围、实施步骤与验收标准 |
| 人工审批 | 用户 | 确认计划与实施边界，批准后开始开发 |
| 开发实施 | Agy · Gemini 3.8 Flash，执行模型 | 按批准计划开发，保持任务上下文 |
| 自动测试 | Agy · Gemini 3.8 Flash，执行模型 | 完成类型检查、生产构建和相关测试 |
| 验收前质量审查 | Codex · GPT-6 Astra，复核模型 | 检查代码质量与遗漏；有问题安排修复和自测 |
| 人工验收 | 用户 | 实际验证功能；功能问题修复后再次验收 |
| 验收后代码复核 | Codex · GPT-6 Astra，复核模型 | 功能确认后复核最终代码；有问题先修复，再交执行模型测试 |
| 本地提交 | Codex · GPT-6 Astra，规划模型 | 实际执行 git commit，仅提交本任务改动 |

工具与模型按角色配置，复核默认跟随规划，也可单独指定。本片使用指定的 Astra / Flash 搭配演示；人工步骤不分配模型。DevFlow 负责衔接阶段与展示状态，测试由执行模型运行，代码质量由复核模型判断，功能由人验收。

依据：`packages/skills/devflow/references/role-and-schedule.md`、`apps/web/src/components/ToolModelDialog.tsx`、`apps/web/src/components/ModelConfigTabs.tsx`、`apps/web/src/components/model-api.ts`。不增加平台验证测试真实性的含义，不把简单八步图当作全部修复分支说明。

计划使用原音乐的 204 拍，约 100 秒。沿用 blur-slide、word-relay-filmstrip、outro-group-photo-launch；新增流程总览为独立说明图，不伪装为产品页面。八步页面保留真实前端，全部业务请求在独立浏览器上下文拦截并注入虚构数据。

修订工程沿用 `project/`，临时渲染、抽帧和缓存集中在 `.tmp/`。保留初版用户要求的截图，新版文章图使用 `v2-` 前缀并更新素材索引。成片两版、工作台、交付说明和独立复核均更新到第二版；完成后清理本轮不再使用的中间文件。
