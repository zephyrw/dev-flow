# DevFlow v0.3.0

本版加入 Claude Code 与 OpenCode 产品适配，集中改善 AGY 账号、模型及额度体验，并修补本地文件边界。继续保持本机免登录、轻量调度。

- **客户端扩展**：Claude Code、OpenCode 支持模型选择、原生会话与权限续接；保留 Codex、AGY 入口。
- **AGY 更快可用**：账号列表先显示快照，额度异步刷新；程序指纹缓存、手动切号优先、通知驱动更新减少重复等待；正常任务不会因切号被主动中止。
- **AGY 模型与额度**：按当前账号提供真实模型清单，支持新 Gemini、Claude 和独立 Argon 周额度；按任务模型处理耗尽与回退，修复身份解析和历史登录误报。
- **执行过程更清楚**：收起已知平台内部恢复指令、重复阶段提示及结果协议空字段，保留用户原文、实际结果和可操作错误。
- **安全与效率**：统一规划文档安全边界，保护并发编辑；修补 Windows 路径别名保护；减少历史读取、缓存失效、调度扫描及闲置目录监听。
- **恢复与启动**：改善规划格式纠正、失效会话恢复、Windows 后台启动隔离与退出诊断。

隔离实测中，账号快照 P95 为 16.5 ms，缓存面板打开 75.7 ms，响应体减少 52.3%，主 JS 减少约 40%。真实账号切换与官方额度响应受外部环境影响，不以虚拟账号数据作速度承诺。

Claude Code 2.1.296、OpenCode 1.19.0、AGY 1.2.12 已在 Windows 隔离项目完成真实规划、开发、自测和质量复核，沿用原生会话进入人工验收。这不表示所有角色、模型及平台均完成真实工作流认证。完整口径见 [验证记录](../test/v0.3.0-验证记录.md) 和 [客户端兼容性](../guide/客户端兼容性.md)。

安装与升级使用 [正式安装指南](../guide/安装与升级.md)。已有实例应先让运行任务结束，再按正常升级流程切换版本；保留配置、账号及历史记录。
