# v0.3.0 验证记录

2026-10-25。本版将 Claude Code、OpenCode 的已实现适配纳入公开发行，并整合 AGY 模型、账号、恢复链路及本地安全和性能优化。保持本机免登录运行，复用现有存储、协调器和通知通道。

## 实现范围

| 范围 | 本版行为 |
| --- | --- |
| Claude Code、OpenCode | 提供模型选择、原生会话和权限续接；授权绑定最新提问及原参数，规划和复核凭证只可核对已授权操作；OpenCode 开始事件确认本轮输入送达，完整文本段保留换行，避免结果代码块被相邻说明粘连。 |
| AGY 模型 | 使用当前账号真实模型清单；支持 Gemini 4 Argon、Gemini 3.8 Flash、Claude 5.5 及原生强度选项；独立额度池不互相覆盖。 |
| AGY 账号 | 保留健康运行与旧轮绑定；手动切换优先，可取消的辅助探测确认退出后让位；停止未确认时保留锁与阻塞状态。 |
| AGY 性能 | 异步流式指纹及按文件身份缓存；单份快照、60 秒刷新有效期、异步受理、通知驱动更新；失败保留真实历史额度。 |
| 本地文件安全 | 计划结果先校验再发布；安全文件句柄、内容冲突检查、数据库失败回退；Windows 大小写与短文件名别名不能绕过保护；文档登记保留短路径写法，避免合法原件误报越界。已批准外部原件只授权原文件。 |
| 执行展示 | 隐藏已知内部准备、恢复及重复状态；结果合同显示摘要与有效内容；用户指导、问答、正常 JSON 和未知正文保留。原始事件不删除。 |
| 后台效率 | 有界历史查询、按归属失效缓存、合并调度唤醒、共享并回收目录监听；Mermaid 按需加载，SVG 缓存有上限。 |
| 恢复与启动 | 安全规范化计划尾部路径、有限格式修正、失效会话显式恢复；Windows 后台启动隔离调用方 Job，并记录退出原因。 |

## 本地验证

工具链为 Node.js 22.23.2、pnpm 11.7.0，平台 Windows x64。全项目类型检查与隔离生产构建通过；主实例的运行文件、数据库、凭据及业务工作树未替换。检查均使用独立测试目录；受影响 Vitest 目标逐文件执行。

受影响 Vitest 文件逐个验证通过，覆盖文档越界、链接、并发编辑、事务回退、Windows 8.3 别名；账号身份、额度池、辅助进程真实退出、不中断切换、晚到结果；模型恢复、权限交互、展示原文、跨数据库连接缓存失效、调度租约和 watcher 回收。其中发布身份链及安装器的三个文件共 43 项通过。最后补跑的文本分段、文档原件、规划复核和路径保护 55 项通过；最终权限授权 48 项、规划及角色交接 21 项、原文输入 3 项、输入错误恢复 2 项通过；输入损坏等用户可操作原因仍保留具体文件信息。

真实 Edge 浏览器 60 项通过，覆盖账号、四客户端模型设置、AGY 混合模型、权限、人机交互、会话恢复、活动历史和执行交付；OpenTabs 另外走通批准、执行和进入人工验收并核对执行过程。正常退出的规划 Run 可发布结果，停止、失败或被替换的 Run 仍拒绝发布。构建 `workspace-69b0cfdb322a39297755` 的 4 项交付浏览器场景再次通过。

Windows 完整 CI 随后发现报告扫描混用了长路径和登记的短路径。将 `TEMP`、`TMP` 指向实际 8.3 路径后，本地复现同组 10 项失败；统一报告扫描路径基准后，原生证据、两组交付复核、文档原件及路径保护共 63 项通过，新增用例仍拒绝越界和受保护文件。最终类型检查、隔离构建通过：`workspace-b2ce97033d54bff0964f`。此次只修复报告路径计算，既有浏览器结果继续适用于未变更的界面；最终四平台结果以发布流水线为准。

macOS Intel 还暴露了浏览器测试的加载竞态：页面详情未返回时，测试将尚未渲染的侧栏误判为关闭，等待不会出现的打开按钮。指导恢复及验收指导测试改用既有侧栏等待函数，并为指导恢复增加延迟详情响应；两个目标各重复三次，共 9 次通过。原有内容断言和 45 秒超时保持不变；全项目类型检查、隔离构建再次通过，产品源码指纹仍为上述构建。

Windows 候选包安装的后台代理超时，最终定位在 `ConvertFrom-Json` 自动发现模块：细化阶段标记后，已确认输入读完，尚未进入进程创建。同一发布环境的[对照验证](https://github.com/zephyrw/dev-flow/actions/runs/40195050098)中，自动发现仍超时，直接加载系统 Utility、CIM 模块则完成安装和确认停止。修复仅在后台代理内关闭自动发现，并按系统路径加载这两个模块，保留原进程隔离和 20 秒超时边界。

输入同时改为 UTF-8 单行 JSON，以行结束符确定完整请求。本地分别复现管道保持打开的超时和同名外部模块导致的启动失败；修复后这两项及进程归属用例通过，中文、引号、内容中的换行完整传递。加上仍适用的启动停止、重启恢复，共 11 项通过；全项目类型检查、隔离构建通过，最终本地构建为 `workspace-86f8eb2d82ad188aef48`。完整四平台候选包检查仍以最终发布提交为准。

## 性能采样

Windows x64、生产网页、4 个虚拟账号、真实本地 HTTP 与浏览器。各项 30 次，均无失败；切换不操作真实凭据。

| 指标 | 中位数 | P95 |
| --- | --- | --- |
| 本地账号快照 | 13.13 ms | 16.54 ms |
| 有效期内额度刷新受理 | 15.39 ms | 17.20 ms |
| 缓存面板打开 | 56.25 ms | 75.74 ms |
| 虚拟账号点击至标记更新 | 139.52 ms | 166.67 ms |
| 已缓存 AGY 程序指纹 | 1.15 ms | 1.43 ms |
| 一万条同域历史中读取最近 5 条 | 10.65 ms | 13.14 ms |

同一组 4 账号数据，旧两个 GET 合计 11,172 B，新快照 5,330 B，减少 52.3%。主 JS 从 1,704,290 B 降至约 1,020,360 B，减少约 40%；Mermaid 的独立资源在需要时加载。

204 MB AGY 程序首次异步指纹耗时 679.92 ms；这是应用缓存冷启动，操作系统文件缓存状态未控制。真实空闲切号 ≤ 2 秒、占用采集时 ≤ 3 秒的目标未据此宣称达成。官方额度响应继续受外部服务影响；10 秒 CLI 与 15 秒整体预算不代替进程退出确认。

历史查询使用现有 `entities_owner` 索引限定账号域，再在 SQLite 中排序并 `LIMIT`；一万条采样未显示需要新索引，暂不增加数据库迁移。数据库仍会扫描该域记录进行排序，不宣称全历史成本恒定。

## 发布条件与限制

公开发行必须通过同一提交的 Windows x64、Linux x64、macOS Intel、macOS Apple Silicon 类型检查、构建及既有 CI 测试，再验证各平台候选包的身份、安装、升级、失败回滚及退出。草稿发布后，匿名公开安装验证另查下载、内置运行时、页面与真实停止。新增验证脚本已用公开 v0.2.9 在独立 Windows 安装目录预验通过，并清除了子进程误继承 PowerShell 7 模块目录的兼容问题；此预验不代替 v0.3.0 的公开安装验证。最终状态以 [发布流水线](https://github.com/zephyrw/dev-flow/actions) 和 [v0.3.0](https://github.com/zephyrw/dev-flow/releases/tag/v0.3.0) 为准。

已知边界：依赖漏洞库和所有实际操作系统权限未作全面审计；文件与数据库回退覆盖本进程失败，不提供跨进程崩溃的分布式原子事务；无法可靠识别来源的材料读取记录保持显示。构建仍有既存的大包与依赖注释警告，未将警告写成检查失败或全部消除。

本轮临时产物集中在 `.cache/release-v0.3.0-20261025/`，发布闭环后停止测试实例、核对引用并清理，只保留本记录和必要安全修复报告。其他任务的历史文档、截图、数据与应用原生会话保留，不随公开代码提交。
