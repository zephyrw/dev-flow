## 已实现

- 任务名称收为顶部单行，流程位置使用节点和连线；细项任务与测试用例的数量及进度条始终可见。
- 主要内容在桌面顶部约 152 像素以下展开；概览不再重复展示进度卡片。最近活动只占一行，点击定位对应执行记录。
- 执行过程改为右侧栏，支持 320—520 像素调整、收起、按任务保存开关、未读提醒、错误标记与回到最新。窄窗口使用抽屉，日志和正文独立滚动。
- 去掉中央执行过程页签。恢复所选模块时重新加载文件差异，旧任务的异步响应不会覆盖新任务的差异列表。
- 保存停止来源、原因、时间、停止前阶段及下一步。真实进程终止异常不再把主动停止改写为失败；历史缺失原因不补造操作者。
- 测试环境分别呈现服务健康检查、数据来源和当前版本集成测试结果；仅有成功输出或零退出码不会开放数据环境的验收入口。
- 检测新页面构建并提示刷新，保留任务、模块和侧栏选择，不自动刷新未保存反馈。
- 使用指南同步三栏操作、进度含义、停止与恢复、环境和页面更新说明。
