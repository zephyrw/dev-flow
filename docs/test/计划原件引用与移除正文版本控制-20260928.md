# 计划原件引用与移除正文版本控制

日期：2026-09-28。范围：按用户要求，DevFlow 不再管理计划正文版本或保存多份正文；保留模型调度、正常人工批准、运行归属、账号和进程身份保护。

## 原因与改动

原先读取链路会将数据库正文与登记的 content_hash 比对，同时 DocumentService、项目材料发布和进度导出分别保存正文副本。现场工作台任务的项目原件完好，数据库缓存与摘要不一致造成错误暂停。

- 页面、下载及模型交接引用同一项目文件；模型交接只传路径与结构化任务信息。
- 删除正文摘要冲突、正文图解数量和未解决问题检查；追加进度或未解决问题不改变任务状态。
- 新文档只在项目原件路径保存；数据库仅存引用，不保存正文。明确的规划修正写回同一文件。
- 停止每轮整改文档副本、版本目录导出、旧缓存自动回填；按需下载进度在内存中生成。
- 页面去除 rN/vN 文档标记，进入计划页重新读取原件。
- 现有历史文件保留，不删除用户或模型可能已补充的内容。历史缓存仅用于无原件引用的数据救援，不覆盖已有原件。
- 内部 Run/审批关联、workflow 并发版本、附加指令与 aside 隔离保留；它们不检查原件正文是否变化。
