## 实现结果

| 问题 | 本次行为 |
|---|---|
| 切换大任务慢 | 先加载摘要和操作入口，再加载详情；缓存任务详情、取消旧请求；WebSocket 保存游标并批量刷新，旧日志向前分页。页面读取使用数据库投影，不再同步反复读取全部任务文件。 |
| 实现声明冒充完成 | 开发完成和验证完成分别显示与导出；开发阶段支持真实测试，结果绑定代码快照；最终验证仍要求当前代码的全部关联证据。 |
| 构建/启动失败中断 | 保留错误输出，允许模型在开发中启动环境、查询健康状态和日志、修复再试；连续失败有次数上限及规划诊断，超出范围进入计划审批。 |
| 服务启动后退出 | 持续记录服务退出，失效旧证据；交付和人工验收前重新核实环境健康。 |
| 授权无法操作 | 工作台展示具体命令、参数、工作目录和原因，批准/拒绝后续接原会话；授权绑定当前计划与命令，消费一次。等待释放模型名额。 |
| 授权操作中断 | 对账确认旧进程退出后标记结果未知；原授权不能重复执行，模型须检查实际效果，重试需新请求。 |
| 无法给中止模型指导 | 原任务侧栏可以发送指导；停止旧轮次、核实资源后续接。历史实现和会话保留。 |
| 不明原因排队 | 区分准备工作区、执行名额、工作目录及测试/环境资源等待；按实际目录加锁，独立目录可并行。 |
| 页面不扫描代码后的过期状态 | 文件变更观察器异步失效相关实现/测试；最终交付继续严格检查完整快照。 |

规划诊断用于失败修复，不替代人工验收后的独立代码复核。复核程序缺失时明确报错，不能合成通过结果。

## 性能

原核查中，计划 SQLite 读取约 3ms、事件查询约 6–12ms；主要耗时来自任务文件校验和事件转换，详情 HTTP 约 1.2–1.9 秒。本次未更换数据库。

在两个任务恢复执行后，各接口串行测量 5 次，包含响应体读取：

| 任务 | 摘要中位数 | 详情中位数 | 详情范围 |
|---|---:|---:|---:|
| 通用平台，88 项实现记录 | 36.8ms | 93.3ms | 83.5–123.5ms |
| CRM，42 项实现记录 | 28.6ms | 95.0ms | 78.6–107.3ms |

摘要第一次 HTTP 样本最高 165.7ms。另一次冷进程内投影首样本 227.1ms，之后摘要约 16–33ms、详情约 44–87ms。以上为本机接口/投影耗时，不等于完整浏览器首屏时间，也不是高并发压测。详情仍有较大响应体，摘要先显示和历史按需加载降低切换阻塞。
