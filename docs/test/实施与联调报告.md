## 联调发现并修复的问题

| 真实失败 | 修复与再次验证 |
|---|---|
| agy 默认项目未加载工作流 MCP | 为每个工作流创建明确 agy 项目，绑定唯一容器资源 |
| 全局许可 Hook 与无人值守执行冲突 | 仅在新建项目中授予 9 个精确 MCP 能力，不改个人全局配置 |
| Windows Hook 的中文 JSON 输入损坏 | 固定编码 PowerShell，显式 UTF-8 stdin/stdout |
| 完整上下文太大被 agy 转存临时文件，执行者读不到 | MCP 按 section/id/offset 分页，大响应按 response_id 分页；随机标记回传重测通过 |
| 未完成声明就提前冻结 | 所有任务有实际声明后才允许 freeze |
| 检查失败后无法返回原范围修复 | 保存失败报告、失效旧证据、恢复 EXECUTING，真实失败→修复→通过集成测试验证 |
| Windows Host 读取中文复核 JSON 失败 | 原生 Host 显式 UTF-8；大段中文、引号和路径逐字节回归通过 |
| Codex 拒绝 Zod 直接生成的 propertyNames | 独立输出 Schema，按实际仓库展开键，所有对象封闭且 required |
| Codex 原生只读命令被运行策略拒绝 | 提供仅可读取冻结清单及证据的 MCP，真实调用确认可读；保持 read-only |
| OpenTabs 新标签页短暂返回空 URL | 等待本轮已登记标签页导航完成，再验证来源 |
| 多仓提交后进程中断可能留下旧 index | 持久化提交意图，CAS 更新引用，重试修复 index 且不重复提交 |
| 修复计划只变测试合同、源码未变时可能重新匹配旧快照 | 每次计划换版强制失效旧测试、验收和运行令牌；保留带 stale 标记的历史复核；相同快照负向回归通过 |
| 中文 Mermaid 标签在 Node 中触发 DOMPurify.addHook 错误 | 在独立 DOM Worker 内进行严格语法校验，中文成功、错误语法拒绝且不污染控制器全局环境 |
| doctor 未读取本仓库内的 .NET 运行时 | 与 Host 管理器采用相同的 DOTNET_ROOT 规则 |

图表解析遵循 [Mermaid parse 接口](https://mermaid.js.org/config/usage)，隔离 DOM 使用 [jsdom](https://github.com/jsdom/jsdom#basic-usage) 默认不执行文档脚本的配置。解析有 30 秒超时，结束后终止 Worker。agy 版本与隔离记录不一致时正式执行拒绝启动，必须更新探针记录。

失败日志保留，例如 [大上下文失败摘要](../../.cache/live-agy/workflow-1789111677302/summary.json)。
